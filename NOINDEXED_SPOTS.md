# Noindexed Spots

Spots with too little verifiable data for a unique page get
`<meta name="robots" content="noindex, follow">` and honest, short text
instead of padded filler. Enrich with real data (official sources, bathymetry,
access details), replace the stub with a hand-written page, remove the meta
tag, then request re-indexing.

Stubs are generated by `scripts/gen-noindex-stubs.py` from the triage classes
in `scripts/rewrites/triage-report.json` (`node scripts/triage-data-richness.js`).
Every 8+ word stub sentence interpolates the spot's own name/species, so the
duplication check passes; stubs are never indexed regardless.
